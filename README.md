# Урок TG04

В данном обновлении проекта произведен рефакторинг логики Telegram-бота и расширен пользовательский интерфейс.

## 🚀 Что нового

* **Добавлен файл `keyboards.py`**
  Выделена отдельная сущность для управления клавиатурами бота (Reply и Inline). Размещение UI-элементов в корне директории `bot` позволяет разгрузить основные обработчики и удобно переиспользовать клавиатуры в разных состояниях.

* **Доработан `handlers.py`**
  Произведен рефакторинг кода. Логические блоки и обработчики сгруппированы в именованные визуальные области (с использованием `# region`), что значительно упрощает навигацию, чтение и сворачивание кода в современных IDE (например, в VS Code).

## 📂 Структура изменений в боте

```text
bot/
├── handlers.py     # Обновлено: добавлено визуальное зонирование кода
├── keyboards.py    # Новое: вынесены шаблоны клавиатур
└── ...
```

## 🛠 Отладка
Для отладки обработчиков и проверки работы клавиатур используется настроенная конфигурация `launch.json`. Бот запускается через management-команду Django (`run_bot`).
